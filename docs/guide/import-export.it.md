# Importazione ed esportazione

## Esportare il vostro CV

Fate clic su **Esporta** nella barra degli strumenti per scaricare il vostro intero CV come file JSON. Questo include tutte le sezioni, gli elementi, le impostazioni e le sezioni personalizzate. Utilizzatelo per i backup o per trasferire il vostro CV su un'altra istanza.

Il file esportato è denominato `cv-data-{lang}.json` (ad esempio, `cv-data-de.json`) e include la lingua del dataset attivo. Questo vi permette di tenere traccia di quale versione linguistica avete esportato.

## Importare i dati

Fate clic su **Importa** e selezionate un file JSON precedentemente esportato. Questo sostituisce i dati attuali del vostro CV con quelli importati. Le sezioni personalizzate e tutte le impostazioni sono incluse.

Se il file importato contiene un campo `language`, l'interfaccia admin si adatta automaticamente a quella lingua dopo l'importazione. Questo significa che se importate un'esportazione di un CV in tedesco, l'interfaccia passa al tedesco così potete continuare a modificare nella lingua corretta.

!!! tip
    Esportate il vostro CV prima di importare, in modo da avere un backup dello stato corrente.
