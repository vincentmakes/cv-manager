# Secções

## Secções Integradas

O CV Manager inclui 7 secções integradas:

| Secção | Descrição |
|--------|-----------|
| **Sobre** | O seu resumo profissional / bio. Suporta texto com múltiplas linhas. |
| **Cronologia** | Gerada automaticamente a partir das suas experiências profissionais. Mostra uma cronologia visual com bandeiras de países. |
| **Experiência** | Histórico profissional com cargo, empresa, datas, localização, bandeira do país e destaques em marcadores. |
| **Certificações** | Certificações profissionais com emissor e datas. |
| **Formação** | Graus, instituições, datas e descrições. |
| **Competências** | Categorias de competências agrupadas com etiquetas individuais. Cada categoria pode ter um ícone personalizado. |
| **Projetos** | Projetos em destaque com descrições, etiquetas de tecnologia e ligações externas. |

Todas as ações de gestão de uma secção estão agora no próprio cabeçalho da secção do conjunto de dados ativo — já não existe um separador de Configurações dedicado às secções.

## Reordenar secções

Cada secção tem uma **pega de arrastar** (ícone ⠿) no canto superior esquerdo. Clique nela para abrir a sobreposição de reordenação, arraste as secções para a ordem pretendida e clique em **OK**. A nova ordem aplica-se tanto à vista de administração como ao site público do conjunto de dados ativo.

## Renomear cabeçalhos de secção

O cabeçalho de cada secção inclui, ao lado do olho de visibilidade, um **ícone de renomear** (lápis com texto):

1. Clique no ícone de renomear da secção que pretende renomear. A secção **Resumo Profissional** é a única exceção — o seu campo de renomeação encontra-se dentro da janela existente "Editar Sobre" como primeiro campo (**Cabeçalho da secção**).
2. Introduza um novo título. Deixe o campo vazio para repor o título predefinido traduzido.
3. O interruptor **Aplicar a todos os conjuntos de dados nesta língua** está ativado por predefinição. Quando está ativo, o novo título aplica-se a todos os conjuntos de dados que partilham a mesma língua do conjunto ativo (por exemplo, todos os conjuntos em português). Desative-o para renomear apenas o conjunto ativo.
4. Clique em **Guardar**.

Os irmãos noutra língua (por exemplo, a versão inglesa do mesmo CV) nunca são afetados por uma renomeação — cada língua mantém o seu próprio título.

## Ocultar secções

O cabeçalho de cada secção tem dois interruptores de visibilidade:

- **Ícone do olho** — mostra / oculta a secção tanto na vista de administração como no site público.
- **Ícone da impressora** — oculta a secção apenas nas impressões / exportações PDF; permanece visível no ecrã. Desativado quando a secção já está oculta.

As secções ocultas mantêm os seus dados — pode reativá-las a qualquer momento.

## Secções personalizadas

Para adicionar uma secção que não está na lista integrada (por exemplo, "Publicações", "Voluntariado" ou uma linha de ligações sociais), passe o rato sobre o espaço entre duas secções da página principal — aparece um marcador tracejado **+ Criar secção personalizada**. Clicar abre a janela de criação e insere a nova secção exatamente nesse ponto.

O cabeçalho de cada secção personalizada contém os mesmos ícones de renomear, visibilidade e visibilidade de impressão das secções integradas, mais um ícone de caixote do lixo para a eliminar.
