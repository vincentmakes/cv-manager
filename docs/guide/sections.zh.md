# 板块

## 内置板块

CV Manager 提供 7 个内置板块：

| 板块 | 描述 |
|------|------|
| **关于我** | 您的职业摘要/简介。支持多行文本。 |
| **时间线** | 根据您的工作经历自动生成。以可视化时间线形式展示，带有国旗图标。 |
| **工作经历** | 工作履历，包含职位名称、公司、日期、工作地点、国旗和要点描述。 |
| **资格认证** | 专业资格认证，包含颁发机构和日期。 |
| **教育背景** | 学位、院校、日期和描述。 |
| **技能** | 分组的技能类别，包含单独的技能标签。每个类别可以设置自定义图标。 |
| **项目** | 精选项目，包含描述、技术标签和外部链接。 |

所有板块管理操作现在都直接位于当前数据集的板块标题栏上——设置中不再有独立的板块选项卡。

## 重新排序板块

每个板块的左上角都有一个**拖拽手柄**（⠿ 图标）。点击它以打开重排覆盖层，拖动板块到所需顺序，然后点击 **确定**。新的顺序同时应用于当前数据集的管理端和公开端。

## 重命名板块标题

每个板块标题栏在可见性眼睛图标旁都有一个**重命名图标**（带文字的铅笔）：

1. 点击要重命名板块的重命名图标。**个人简介** 板块是唯一例外——它的重命名字段位于已有的"编辑简介"弹窗中，作为第一个字段（**板块标题**）。
2. 输入新标题。字段留空可恢复为翻译后的默认标题。
3. **应用到该语言下的所有数据集** 开关默认开启。开启时，新标题将应用于与当前数据集语言相同的所有数据集（例如所有中文数据集）。关闭后则仅重命名当前数据集。
4. 点击 **保存**。

其他语言的兄弟数据集（例如同一份简历的英文版本）不会受到重命名的影响——每种语言都保留自己的标题。

## 隐藏板块

每个板块标题栏有两个可见性开关：

- **眼睛图标** — 在管理端和公开站点同时显示/隐藏该板块。
- **打印机图标** — 仅在打印/PDF 导出中隐藏该板块；屏幕上仍然可见。当板块本身被隐藏时该按钮被禁用。

隐藏的板块会保留其数据——您可以随时重新启用。

## 自定义板块

若要添加内置列表中没有的板块（例如"出版物"、"志愿活动"或一行社交链接），将鼠标悬停在主页面上两个板块之间的空白处——会出现一个虚线占位符 **+ 创建自定义板块**。点击它会打开创建对话框，并将新板块精确插入到悬停位置之后。

每个自定义板块的标题栏包含与内置板块相同的重命名、可见性和打印可见性图标，外加一个用于删除的垃圾桶图标。
