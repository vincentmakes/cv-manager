# Sezioni

## Sezioni predefinite

CV Manager include 7 sezioni predefinite:

| Sezione | Descrizione |
|---------|-------------|
| **Informazioni personali** | Il vostro riassunto professionale / biografia. Supporta testo su più righe. |
| **Timeline** | Generata automaticamente dalle esperienze lavorative. Mostra una timeline visuale con bandiere dei paesi. |
| **Esperienze** | Storico lavorativo con titolo professionale, azienda, date, sede, bandiera del paese e punti salienti. |
| **Certificazioni** | Certificazioni professionali con ente certificatore e date. |
| **Formazione** | Titoli di studio, istituti, date e descrizioni. |
| **Competenze** | Categorie di competenze raggruppate con etichette per le singole competenze. Ogni categoria può avere un'icona personalizzata. |
| **Progetti** | Progetti in evidenza con descrizioni, etichette tecnologiche e link esterni. |

Tutte le azioni di gestione di una sezione si trovano ora nell'intestazione della sezione stessa del dataset attivo — non c'è più una scheda Impostazioni dedicata alle sezioni.

## Riordinare le sezioni

Ogni sezione ha una **maniglia di trascinamento** (icona ⠿) nell'angolo superiore sinistro. Cliccatela per aprire l'overlay di riordino, trascinate le sezioni nell'ordine desiderato e cliccate su **OK**. Il nuovo ordine si applica sia alla vista admin che al sito pubblico del dataset attivo.

## Rinominare le intestazioni delle sezioni

L'intestazione di ogni sezione include, accanto all'occhio di visibilità, un'**icona di rinomina** (matita con testo):

1. Cliccate sull'icona di rinomina della sezione che volete rinominare. La sezione **Profilo professionale** è l'unica eccezione — il suo campo di rinomina si trova all'interno della finestra esistente "Modifica informazioni" come primo campo (**Intestazione della sezione**).
2. Digitate il nuovo titolo. Lasciate il campo vuoto per ripristinare il titolo predefinito tradotto.
3. L'interruttore **Applica a tutti i dataset in questa lingua** è attivo per impostazione predefinita. Quando è attivo, il nuovo titolo si applica a tutti i dataset che condividono la stessa lingua del dataset attivo (ad esempio tutti i dataset italiani). Disattivatelo per rinominare solo il dataset attivo.
4. Cliccate su **Salva**.

I dataset fratelli in un'altra lingua (ad esempio la versione inglese dello stesso CV) non vengono mai toccati da una rinomina — ogni lingua conserva il proprio titolo.

## Nascondere le sezioni

L'intestazione di ogni sezione ha due interruttori di visibilità:

- **Icona occhio** — mostra / nasconde la sezione sia nella vista admin che sul sito pubblico.
- **Icona stampante** — nasconde la sezione solo negli export di stampa / PDF; rimane visibile a schermo. Disabilitata quando la sezione è già nascosta.

Le sezioni nascoste conservano i propri dati — potete riattivarle in qualsiasi momento.

## Sezioni personalizzate

Per aggiungere una sezione che non è presente nell'elenco predefinito (ad esempio "Pubblicazioni", "Volontariato" o una riga di link social), posizionate il mouse sullo spazio tra due sezioni della pagina principale — apparirà un segnaposto tratteggiato **+ Crea sezione personalizzata**. Un clic apre la finestra di creazione e inserisce la nuova sezione esattamente in quel punto.

L'intestazione di ogni sezione personalizzata contiene le stesse icone di rinomina, visibilità e visibilità di stampa delle sezioni predefinite, più un'icona cestino per eliminarla.
