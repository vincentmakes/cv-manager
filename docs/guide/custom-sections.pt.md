# Seções Personalizadas

Seções personalizadas permitem que você adicione qualquer conteúdo que não se encaixe nas seções integradas.

As secções personalizadas são criadas diretamente no CV — já não existe um separador dedicado nas Configurações.

## Adicionar uma Secção Personalizada

Dois pontos de entrada equivalentes:

- **Entre duas secções** — passe o cursor pelo espaço logo abaixo de qualquer secção existente. Aparece uma pílula tracejada **+ Adicionar secção personalizada**; clique para abrir a caixa de diálogo de criação. A nova secção é inserida logo abaixo da secção sobre a qual passou o cursor.
- **No fundo do CV** — a mesma pílula **+ Adicionar secção personalizada** está sempre visível sob a última secção, como ajuda para descobrir a funcionalidade. Ao clicar, adiciona uma nova secção no fim.

Na caixa de diálogo:

1. Digite um nome para a secção
2. Escolha um tipo de layout (ver abaixo)
3. Guarde — a nova secção aparece no CV e é guardada automaticamente no conjunto de dados ativo

## Gerir uma Secção Personalizada

Cada secção personalizada tem três botões de ícone no seu cabeçalho:

- **Eliminar** (ícone de lixo) — remove a secção e todos os seus itens após confirmação
- **Renomear** (ícone de lápis) — abre uma pequena caixa de diálogo para alterar o título da secção
- **Visibilidade** (ícone de olho) — ativa ou desativa a exibição da secção no CV publicado

O tipo de layout é escolhido uma única vez no momento da criação e não pode ser alterado depois. Se precisar de um layout diferente, crie uma nova secção e mova os itens para lá.

## Tipos de Layout

| Layout | Melhor Para |
|--------|-------------|
| **Grade de 2 Colunas** | Itens em pares como idiomas e proficiência, ferramentas e nível de experiência |
| **Grade de 3 Colunas** | Itens compactos como prêmios, publicações ou credenciais curtas |
| **Lista Vertical** | Itens sequenciais com links opcionais, como trabalho voluntário ou associações |
| **Grade de Cartões** | Itens ricos com título, subtítulo, descrição e link — como peças de portfólio |
| **Links Sociais** | Links específicos de plataformas com ícones (LinkedIn, GitHub, Twitter/X, YouTube, Instagram, Dribbble, Behance, Website, Email, Telefone ou Personalizado) |
| **Marcadores** | Listas com marcadores agrupados, similar aos destaques de experiência — ótimo para conquistas-chave ou competências |
| **Texto Livre** | Bloco de texto simples com quebras de linha preservadas — similar à seção Sobre, útil para cartas de apresentação, declarações pessoais ou qualquer conteúdo de formato livre |
| **Grade de Imagens** | Galeria de imagens com legendas opcionais — ótimo para portfólios, certificados ou amostras de trabalho visual |
| **Experiências Adicionais** | Entradas de tipo experiência (cargo, empresa, datas, destaques, logotipo) — estende seu histórico profissional sem se misturar com a seção principal de Experiência |

## Grade de Imagens

O layout **Grade de Imagens** exibe imagens em uma grade responsiva com legendas opcionais.

1. Crie uma seção personalizada e selecione **Grade de Imagens** como tipo de layout
2. Escolha o número de **colunas da grade** (1, 2 ou 3 — padrão é 3)
3. Clique em **Adicionar Imagem** para enviar imagens (JPEG, PNG ou WebP, máx. 5MB)
4. Opcionalmente adicione uma **legenda** abaixo de cada imagem

As imagens são centralizadas e mantêm suas proporções. No modo de 3 colunas, as imagens são exibidas quadradas para uma aparência uniforme.

## Experiências Adicionais

O layout **Experiências Adicionais** cria entradas de tipo experiência idênticas à seção integrada de Experiência Profissional. Cada item inclui:

- **Cargo** e **nome da empresa/organização**
- **Datas de início e término** (com "Presente" opcional para cargos atuais)
- **Localização** e **código do país**
- **Destaques** (conquistas-chave, um por linha)
- **Logotipo opcional** (mesmo fluxo de envio/reutilização dos logotipos de empresas)

### Mostrar na Linha do Tempo Profissional

Ao gerenciar itens em uma seção de Experiências Adicionais, você pode ativar **"Mostrar itens na Linha do Tempo Profissional"**. Isso mescla as entradas de experiência adicional na visualização principal da linha do tempo — elas aparecem ao lado de suas experiências profissionais regulares com suporte completo para ramificações, logotipos e exibição de duração.

## Opção Ocultar Título

Para layouts de grade, lista, cartão e marcadores, cada item possui uma caixa de seleção **"Ocultar título"**. Quando ativada, o item é exibido sem o título — útil quando o conteúdo fala por si só.

## Gerenciando Itens de Seções Personalizadas

Clique em **Gerenciar Itens** em qualquer seção personalizada para adicionar, editar, reordenar ou excluir itens dentro dessa seção.

!!! note "Nota"
    Não há limite fixo para seções personalizadas. Crie quantas precisar.
