# 导入与导出

## 导出简历

点击工具栏中的**导出**即可将整份简历下载为 JSON 文件。导出内容包括所有板块、条目、设置和自定义板块。可用于备份或将简历迁移到另一个实例。

导出的文件命名为 `cv-data-{lang}.json`（例如 `cv-data-de.json`），其中包含活动数据集的语言。这让您可以追踪导出的是哪个语言版本。

## 导入数据

点击**导入**并选择之前导出的 JSON 文件。此操作会用导入的数据替换当前的简历数据。自定义板块和所有设置均包含在内。

如果导入的文件包含 `language` 字段，管理界面会在导入后自动切换到该语言。这意味着如果您导入一份德语简历的导出文件，界面会切换到德语，以便您可以在正确的语言环境下继续编辑。

!!! tip
    导入前请先导出当前简历，以便保留当前状态的备份。
