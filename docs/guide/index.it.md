Questa guida copre tutto ciò che potete fare con l'interfaccia admin di CV Manager.

- **[Sezioni](sections.md)** — Sezioni predefinite, riordinamento, rinominazione e nascondimento
- **[Modifica dei contenuti](editing.md)** — Profilo, immagini, esperienze lavorative, loghi, certificazioni, formazione, competenze e progetti
- **[Sezioni personalizzate](custom-sections.md)** — Creazione di sezioni aggiuntive con 7 tipi di layout
- **[Timeline](timeline.md)** — Timeline generata automaticamente con supporto per posizioni parallele
- **[Tema e aspetto](theme.md)** — Colori e opzioni per il formato data
- **[Lingua](language.md)** — Lingua dell'interfaccia admin, lingua del contenuto del CV e varianti linguistiche
- **[Dataset](datasets.md)** — Salvataggio di più versioni del CV e varianti linguistiche per diversi destinatari
- **[Stampa e PDF](print-pdf.md)** — Esportazione del CV con numeri di pagina e suddivisione configurabili
- **[Importazione ed esportazione](import-export.md)** — Backup e ripristino dei dati del CV
- **[Esportazione sito statico](static-site.md)** — Pubblica il vostro CV su GitHub Pages, Cloudflare Pages o qualsiasi hosting statico

## Aggiornamenti e versione

Aprite le **Impostazioni** — la versione corrente (ad esempio, `v1.11.0`) è mostrata nell'angolo in basso a sinistra del footer della finestra modale.

CV Manager verifica automaticamente su GitHub la disponibilità di versioni più recenti. Se un aggiornamento è disponibile, appare un banner blu sotto la barra degli strumenti:

> **Aggiornamento disponibile: v1.12.0** (versione attuale v1.11.0) — *Novità*

Il link "Novità" apre il changelog. Potete chiudere il banner con il pulsante X.

!!! note
    Il controllo della versione viene memorizzato nella cache per 24 ore. Riavviate il server (o il container Docker) per svuotare la cache e forzare un nuovo controllo.
