# 语言

## 管理界面语言

点击工具栏中的**地球图标**切换管理界面语言。下拉网格中显示所有可用语言——点击即可立即应用。

**支持的语言：** 英语、德语（Deutsch）、法语（Français）、荷兰语（Nederlands）、西班牙语（Español）、意大利语（Italiano）、葡萄牙语（Português）、中文。

语言设置仅影响管理界面的标签、按钮和菜单。您的偏好设置会被保存并在各次会话间保持。

## 简历内容语言

与界面语言不同，每个已保存的数据集都有自己的**内容语言**——即简历内容所使用的语言。内容语言在CV管理器中以徽章形式（EN、DE、FR 等）显示在每个数据集行上。

当您加载一个数据集时，管理界面会自动切换到匹配其内容语言。这意味着如果您加载一份德语简历，界面也会切换到德语，这样板块标题和表单标签就与您正在编辑的内容使用相同的语言。

### 更改数据集的语言

要更改现有数据集的分配语言：

1. 打开 **CV管理器**
2. 点击数据集行上的**语言徽章**（例如 EN）
3. 从选择器中选择新语言

这将重新分配语言代码而不更改内容本身——对于在初始设置时默认为英语的数据集非常有用。

## 语言变体

您可以创建同一份简历的**多个语言变体**。例如，维护一份英文版和一份德文版，它们共享相同的结构但内容独立。

有关创建和管理语言变体的详情，请参阅[数据集与语言变体](datasets.md#语言变体)。

## 公开站点语言切换

当默认数据集有语言兄弟时，访客可以在公开站点上切换语言：

- **默认语言**在 `/` 上展示
- 其他语言在 `/{lang}` 上可用（例如 `/de`、`/fr`）
- 公开站点上会出现语言切换按钮，供访客在可用语言之间切换

对于非默认的共享数据集，语言变体在 `/v/slug/{lang}` 上展示。
