# Sections

## Built-in Sections

CV Manager comes with 7 built-in sections:

| Section | Description |
|---------|-------------|
| **About** | Your professional summary / bio. Supports multi-line text. |
| **Timeline** | Auto-generated from your work experiences. Shows a visual timeline with country flags. |
| **Experience** | Work history with job title, company, dates, location, country flag, and bullet-point highlights. |
| **Certifications** | Professional certifications with provider and dates. |
| **Education** | Degrees, institutions, dates, and descriptions. |
| **Skills** | Grouped skill categories with individual skill tags. Each category can have a custom icon. |
| **Projects** | Featured projects with descriptions, technology tags, and external links. |

Every section management action is inline on the section header of the active dataset — there is no separate Settings tab for sections.

## Reordering Sections

Each section has a **drag handle** (⠿ icon) in its top-left corner. Click it to open the reorder overlay, drag sections into the order you want, and click **OK**. The new order applies to both the admin view and the public site for the active dataset.

## Renaming Section Headings

Each section header has a **rename icon** (pencil-with-text) next to the visibility eye:

1. Click the rename icon on the section you want to rename. The **Professional Summary** section is the one exception — its rename field lives inside the existing "Edit About" profile modal as the first field (**Section heading**).
2. Type a new title. Leave the field empty to reset to the translated default.
3. The **Apply to all datasets in this language** toggle is on by default. When it's on, the new title applies to every dataset sharing the active dataset's language (e.g., every English dataset). Turn it off to rename just the active dataset.
4. Click **Save**.

Siblings in a different language (for example, the French version of the same CV) are never affected by a rename — every language keeps its own title.

## Hiding Sections

Each section header has two visibility toggles:

- **Eye icon** — shows / hides the section on both the admin view and the public site.
- **Printer icon** — hides the section from print / PDF exports only; it stays visible on screen. Disabled when the section itself is hidden.

Hidden sections keep their data, so you can toggle them back on at any time.

## Custom Sections

To add a section that isn't in the built-in list (for example, "Publications", "Volunteer Work", or a social-links row), hover the gap between two sections on the main page — a dashed "**+ Create custom section**" placeholder appears. Clicking it opens the creation dialog and inserts the new section exactly where you were hovering.

Each custom section header carries the same rename, visibility and print-visibility icons as the built-in ones, plus a trash icon to delete it.
