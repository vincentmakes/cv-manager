# 数据集与语言变体

## 数据集的工作原理

数据集是您简历的保存快照。其中一个数据集始终是**默认**的——这是访客在您的根 URL（`/`）看到的版本。您可以为不同受众创建额外的数据集（例如技术简历、管理简历），使用不同语言，并通过各自的 URL 分享。

首次安装 CV Manager 时，系统会自动从您的简历数据创建一个"默认"数据集。您在管理端所做的所有编辑都会**自动保存**回当前活动的数据集——无需单独的"保存"步骤。

## CV管理器

点击工具栏中的 **CV管理器**，打开统一的弹窗进行所有数据集操作：保存、加载、创建版本、添加语言、设置默认值和管理可见性。

弹窗有两个区域：

- 顶部的**另存为表单**——名称字段、语言选择器和保存按钮
- 下方的**已保存简历列表**——按基础名称分组，包含所有管理操作

### 保存新数据集

名称字段预填为当前活动数据集的名称。语言下拉菜单默认为当前活动语言。

- **输入新名称**并点击蓝色的**另存为新简历 "…"**按钮来创建全新的数据集
- **点击列表中的现有行**来填充名称字段——按钮变为橙色的**覆盖 "…"**（需确认）

### 数据集列表

每个已保存的简历显示为一个**组**，组头显示基础名称、**+ 新版本**按钮和版本/语言数量徽章。

在每个组内，每个语言变体是一行：

```
○  EN  v2  Full Stack Developer v2     /v/full-stack-dev/en   16/04/2026   [加载]  ⋮
```

- **单选按钮**（○）——选择访客在 `/` 上看到的数据集（默认值）
- **语言徽章**（EN）——该变体的内容语言
- **版本徽章**（v2）——当组内有多个版本时显示
- **名称**——数据集名称
- **URL**——公开 URL 路径（如果是共享或默认的）
- **日期**——最后修改时间
- **加载**——切换到编辑此数据集
- **⋮**（溢出菜单）——额外操作

### 溢出菜单（⋮）

每行的溢出菜单包含：

| 操作 | 描述 |
|------|------|
| **设为共享 / 设为私密** | 切换在 `/v/slug` 上的公开可见性（默认数据集及其语言兄弟隐藏此选项） |
| **更改语言** | 重新分配此数据集的语言代码 |
| **预览** | 在新标签页中打开已保存的版本 |
| **复制 URL** | 将公开或预览 URL 复制到剪贴板 |
| **删除** | 永久删除（默认数据集不可删除） |

## 版本

共享相同基础名称的数据集会分组显示。例如，`Frontend Engineer`、`Frontend Engineer v2` 和 `Frontend Engineer v3` 在共享标题下显示为一个整体。

### 创建新版本

点击组头中的 **+ 新版本**。名称字段会自动填充下一个版本号（例如 `Frontend Engineer v4`）。保存后，新版本会：

- 获得相应的版本徽章（v4）
- 与其兄弟版本共享相同的 URL slug
- 继承上一版本的所有语言变体

### 可折叠的旧版本

当一个组有多个版本时，只显示最新的版本。**"N 个旧版本"**切换按钮可以展开查看所有版本。如果您正在编辑的数据集或默认数据集在旧版本中，会自动展开以便您始终可以看到它。

!!! tip
    使用 `基础名称 vN` 的命名约定（例如 `Frontend Engineer`、`Frontend Engineer v2`）即可获得自动版本分组和下一版本建议。

## 语言变体

每个数据集版本可以有多个语言变体——例如，同一份简历的英文和德文版本，共享相同的结构但内容独立。

### 添加语言变体

1. 打开 **CV管理器**
2. 点击组头上的 **+ 添加语言**（或从"另存为"表单使用 **⋮ → 添加语言** 流程）
3. 选择目标语言并保存

新变体以现有内容的副本开始。管理界面会自动切换到新语言，以便您开始翻译。

### 切换语言

当编辑具有语言兄弟的数据集时，工具栏下方的活动数据集横幅中会出现一个**语言切换器**。点击语言代码进行切换——您当前的工作会先自动保存，然后加载另一个变体，界面语言也会随之调整。

### 结构同步

对**结构**的更改——板块顺序、可见性、自定义板块布局和条目数量——会自动传播到所有语言兄弟。**内容**（文本、标题、描述）保持每种语言独立，因此您可以自由翻译而无需担心布局偏移。

### 更改数据集的语言

点击任何行上的**语言徽章**打开选择器，重新分配其语言代码。这对于在初始设置时默认为英语的旧数据集非常有用。

## 设置默认值

默认数据集是访客在您的根 URL（`/`）上看到的版本。要更改它：

1. 打开 **CV管理器**
2. 点击您想设为默认的数据集旁边的**单选按钮**（○）
3. 更改立即生效

默认数据集的语言兄弟会自动通过 `/{lang}`（例如 `/de`、`/fr`）访问——无需单独的公开切换。

!!! note
    公开站点展示的是已保存的默认数据集，而不是您的实时编辑。您可以在管理端安全地进行实验，不会影响访客看到的内容。

## 公开版本化 URL

非默认数据集可以通过自己的 URL 分享。使用 **⋮ → 设为共享** 操作将数据集公开到 `/v/slug`。多个数据集可以同时公开。

- **默认数据集**：在 `/` 上展示
- **默认数据集的语言兄弟**：在 `/{lang}` 上展示（例如 `/fr`）
- **共享数据集**：在 `/v/slug` 或 `/v/slug/{lang}` 上展示
- **私密数据集**：只能从管理界面预览

!!! tip "复制 URL"
    点击每行上显示的 URL 路径，即可将完整的公开 URL 复制到剪贴板。
