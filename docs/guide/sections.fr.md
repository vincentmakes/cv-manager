# Sections

## Sections intégrées

CV Manager est fourni avec 7 sections intégrées :

| Section | Description |
|---------|-------------|
| **À propos** | Votre résumé professionnel / biographie. Prend en charge le texte multiligne. |
| **Chronologie** | Générée automatiquement à partir de vos expériences professionnelles. Affiche une frise chronologique visuelle avec des drapeaux de pays. |
| **Expérience** | Parcours professionnel avec intitulé de poste, entreprise, dates, lieu, drapeau de pays et points clés. |
| **Certifications** | Certifications professionnelles avec organisme et dates. |
| **Formation** | Diplômes, établissements, dates et descriptions. |
| **Compétences** | Catégories de compétences regroupées avec des étiquettes individuelles. Chaque catégorie peut avoir une icône personnalisée. |
| **Projets** | Projets mis en avant avec descriptions, étiquettes de technologies et liens externes. |

Toutes les actions de gestion d'une section se trouvent désormais dans l'en-tête de la section du jeu de données actif — il n'y a plus d'onglet Paramètres dédié aux sections.

## Réorganiser les sections

Chaque section possède une **poignée de glissement** (icône ⠿) dans son coin supérieur gauche. Cliquez dessus pour ouvrir le calque de réorganisation, faites glisser les sections dans l'ordre souhaité, puis cliquez sur **OK**. Le nouvel ordre s'applique à la vue d'administration et à la page publique du jeu de données actif.

## Renommer les titres de section

L'en-tête de chaque section comporte une **icône de renommage** (crayon avec texte) à côté de l'œil de visibilité :

1. Cliquez sur l'icône de renommage de la section souhaitée. La section **Résumé professionnel** est la seule exception — son champ de renommage est intégré dans la fenêtre « Modifier la présentation » existante sous forme de premier champ (**Titre de la section**).
2. Saisissez un nouveau titre. Laissez le champ vide pour revenir au titre par défaut traduit.
3. L'interrupteur **Appliquer à tous les jeux de données dans cette langue** est activé par défaut. Lorsqu'il est activé, le nouveau titre s'applique à tous les jeux de données qui partagent la même langue que le jeu actif (par exemple, tous les jeux de données français). Désactivez-le pour ne renommer que le jeu actif.
4. Cliquez sur **Enregistrer**.

Les jeux frères dans une autre langue (par exemple la version anglaise du même CV) ne sont jamais affectés par un renommage — chaque langue conserve son propre titre.

## Masquer des sections

L'en-tête de chaque section propose deux interrupteurs de visibilité :

- **Icône œil** — affiche / masque la section à la fois dans l'administration et sur le site public.
- **Icône imprimante** — masque la section uniquement lors de l'impression / export PDF ; elle reste visible à l'écran. Désactivée lorsque la section est déjà masquée.

Les sections masquées conservent leurs données — vous pouvez les réactiver à tout moment.

## Sections personnalisées

Pour ajouter une section absente de la liste intégrée (par exemple « Publications », « Bénévolat » ou une rangée de liens sociaux), survolez l'espace entre deux sections de la page principale — un emplacement en pointillés **+ Créer une section personnalisée** apparaît. Un clic ouvre la fenêtre de création et insère la nouvelle section exactement à cet endroit.

L'en-tête de chaque section personnalisée comporte les mêmes icônes de renommage, visibilité et visibilité à l'impression que les sections intégrées, plus une icône corbeille pour la supprimer.
