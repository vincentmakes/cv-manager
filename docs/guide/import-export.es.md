# Importar y exportar

## Exportar su CV

Haga clic en **Exportar** en la barra de herramientas para descargar su CV completo como un archivo JSON. Esto incluye todas las secciones, elementos, configuraciones y secciones personalizadas. Utilice esto para copias de seguridad o para transferir su CV a otra instancia.

El archivo exportado se llama `cv-data-{idioma}.json` (por ejemplo, `cv-data-de.json`) e incluye el idioma del conjunto de datos activo. Esto le permite realizar un seguimiento de qué versión de idioma exportó.

## Importar datos

Haga clic en **Importar** y seleccione un archivo JSON previamente exportado. Esto reemplaza los datos actuales de su CV con los datos importados. Las secciones personalizadas y todas las configuraciones están incluidas.

Si el archivo importado contiene un campo `language`, la interfaz de administración cambia automáticamente a ese idioma después de la importación. Esto significa que si importa una exportación de CV en alemán, la interfaz cambia a alemán para que pueda continuar editando en el idioma correcto.

!!! tip
    Exporte su CV antes de importar, para tener una copia de seguridad del estado actual.
