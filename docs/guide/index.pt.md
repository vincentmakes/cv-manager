## Atualizações e versão

Abra as **Configurações** — a versão atual (por exemplo, `v1.11.0`) é exibida no canto inferior esquerdo do rodapé da janela modal.

O CV Manager verifica automaticamente no GitHub se há versões mais recentes. Se uma atualização estiver disponível, um banner azul aparece abaixo da barra de ferramentas:

> **Atualização disponível: v1.12.0** (está na v1.11.0) — *Novidades*

O link "Novidades" abre o changelog. Pode dispensar o banner com o botão X.

!!! note
    A verificação de versão é armazenada em cache durante 24 horas. Reinicie o seu servidor (ou container Docker) para limpar a cache e forçar uma nova verificação.
